Detailed Description

Utility helpers of LightHub.

Miscellaneous platform and protocol helpers: JSON (aJSON) getters and object creation, command execution (executeCommand), MQTT topic building (setTopic), number/byte/string parsing, IP address utilities, CRC16 of JSON objects, pin access and logging.
