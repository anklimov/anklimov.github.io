Detailed Description

Base class of output driver modules (one per channel type).

abstractOut is the interface between the item core and a concrete device driver (out_dmx, out_relay, out_Modbus, ...). The driver is created by driverFactory, linked to the current item via link(), controls the hardware in Ctrl() and reports activity via isActive(). Drivers are shared between items of the same channel type, so all state must be derived from the linked item rather than stored per-instance.
