Detailed Description

CCS811 eCO2 / eTVOC air-quality sensor input (IN_CCS811 = 5).

Reads the MOX air-quality sensor over I2C at the fixed address CCS811_ADDR (0x5A). Polls the sensor when new data is available, suppresses spontaneous calculation errors (CO2 >= 10000 ppm) and publishes the readings on the input "in" section:

  • /CO2 - estimated CO2 concentration (ppm);
  • /TVOC - estimated total volatile organic compounds (ppb);
  • /base - sensor baseline value.

The humidity/temperature measured by the companion HDC1080 input are forwarded here via setEnvironmentalData() to improve accuracy.
