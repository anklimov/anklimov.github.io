Detailed Description

Base class of input driver modules (sensors, encoders, ...).

abstractIn extends abstractCh for drivers attached to an Input. The in pointer references the Input's config entry; the protected publish() helpers convert the measured value to a string and publish it to the MQTT topic given by the "emit" field of the input.
