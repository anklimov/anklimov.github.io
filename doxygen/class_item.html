Detailed Description

A single LightHub item (virtual channel).

Item wraps one entry of the global items JSON object: a virtual channel of a given type (CH_*) with its arguments, current value, last command, optional extension data and a driver instance. Items are the core abstraction of the system: physical outputs (relays, DMX, Modbus, AC), groups and services are all items, addressed by name ("name", "name/subItem" or "name/subItem/suffix").

All external control is funneled through the Ctrl() overloads; the resulting state is published to MQTT (and CAN when enabled) via SendStatus()/SendStatusImmediate().
