Detailed Description

32-bit parameter storage of itemCmd.

Holds a signed/unsigned number, float or string pointer; a HSV255 color (h:9, s, v, colorTemp:7) and the same with signed fields; or a NeoPixel-packed BGWR color (b, g, r, w) compatible layout.
