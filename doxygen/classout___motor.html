Detailed Description

Motorized gate/shutter driver with analog position feedback, channel type CH_MOTOR = 12.

Drives the up/down motor pins (with PWM speed control where the pins support PWM) until the analog feedback reaches the target position 0-255. No more than MOTOR_QUOTE (2) motors run simultaneously, and the motor is stopped after maxOnTime ms regardless of position.

JSON config (itemArg): [pinUp, pinDown, pinFeedback, fbOpen, fbClosed, maxOnTime_ms(default 10000)]

  • negative pin numbers invert the output; defaults pinUp=32, pinDown=33;
  • fbOpen / fbClosed: raw analog readings at fully open / fully closed.

Ctrl: /set <0-255> - target position; /cmd on / off (off drives to 0).

The current position (0-255) is derived from the analog feedback pin.
