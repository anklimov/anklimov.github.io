Detailed Description

Air conditioner driver (Haier IR-over-UART protocol), channel type CH_AC = 10.

Talks to a Haier AC over UART at 9600 baud using 13-byte request frames and 37-byte status frames (frame check = sum of bytes). Periodically polls the AC unit and applies control commands.

JSON config (itemArg): [portNum(0-3), callbacksObj]

  • portNum: 0 = default port (Serial3, or USB-CDC Serial), 1..3 = Serial1..Serial3;
  • callbacksObj (optional): object with keys "fan", "set", "cmd", "temp" holding execution objects invoked on every polled status update.

Ctrl commands:

  • /set 16-40 - set temperature;
  • /cmd - AUTO / HEAT / COOL / FAN_ONLY / DRY, plus ON / OFF;
  • /fan - LOW / MEDIUM / HIGH / AUTO / OFF, or a 0-255 value;
  • /mode <number> - raw mode code;
  • subitems: "lock" ON/OFF, "swing" ON/OFF, "queit" (sic) ON/OFF, "raw".

Published status topics: /set, /temp, /mode, /cmd, /fan, /fresh, /lock, /quiet, /compressor, /swing.
