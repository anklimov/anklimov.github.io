Detailed Description

Multi-zone ventilation controller for a shared AC unit, channel type CH_MULTIVENT = 18.

Manages several ventilation zones (per-zone setpoints, PID control and airflow capacity) and steers the shared AC unit (mode, fan level and setpoint), including boost on PID imbalance and suppression of redundant commands to the AC.

JSON config (itemArg = OBJECT of zones). The key "" is the shared AC node. Zone keys: "set" (setpoint), "fan", "cmd", "V" (airflow capacity, default 60), "pid" ([kP, kI, kD, dT(default 5 s)]), "AlarmTime" (default 120 s), "AlarmValue". AC node keys: "boost" (default 230), "supress" (bitmask: 1 fan, 2 set, 4 cmd, 7 all; default 0xF), "turnbyfan", "overridecmd", "onextcmd", "cas" (cascade execution object).

Ctrl commands:

  • /fan - LOW / MEDIUM / HIGH (64/128/255), a 0-255 value, AUTO (passive mode) or OFF;
  • /cmd - ON, OFF, HEAT, COOL, HEATCOOL, DRY, FAN, AUTO, FREEZE, UNFREEZE;
  • /set - zone temperature setpoint;
  • /val - zone temperature (PID input).
  • Without a subitem the call is AC feedback (/val, /fan, /set, /mode, /cmd).

Poll: runs the per-zone PID loops, redistributes airflow by V capacity, applies boost/suppress and sends the resulting fan level and mode to the AC.
