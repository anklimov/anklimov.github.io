Detailed Description

Base class for multi-channel color output drivers (PWM, LED strip).

Holds the base pin address and the number of configured channel addresses and implements the common color control logic; the actual output is delegated to the derived PixelCtrl().

Color state is stored in HSV: hue 0..365, saturation 0..100, value 0..255, plus an optional color temperature (153..500 mireds) used by RGBWW channels to mix the two white channels.

Control (Ctrl) suffixes: /set (percent or color value), /HSV, /cmd ON/OFF (ON restores the stored value, OFF clears it).
