Detailed Description

Per-input runtime state, packed into the JSON object's valueint.

Digital layout: toggle flags of 3 contacts, last raw value, delayed-state flag, bounce counter, current/required state (IS_*) and a 16-bit timestamp. Analog layout: logic state plus a 16-bit current ADC value.
