Detailed Description

DMX input/output (and Art-Net) support.

DMX output uses a hardware USART on the SAM3X8E (Due) and a software bit-banged driver (DmxSimple, pin 3/18) on AVR; DMX input uses DMXSerial on AVR and the hardware USART on the Due. Received DMX/Art-Net channels are mapped to items via the dmxArr configuration.

◆ DMXput()

void DMXput ( void )

Propagates received DMX input frames to the mapped items.

DMX in/out is handled per platform: on the SAM3X8E (Due) a hardware USART (DmxDue) is used for both input and output; on AVR a software bit-banged driver (DmxSimple for output on pin 3/18, DMXSerial for input). ESP8266/ESP32 use ESPDMX.
