Detailed Description

Generic Modbus register channel driver, channel type CH_MBUS = 14.

The channel is described by a template from the global Modbus template table: registers are polled periodically, mapped to item parameters and fired as execution actions, and control commands are written back to the registers. Last sent / last measured values are tracked per parameter in the "@V" / "@S" marks to suppress redundant writes and re-executions.

JSON config (itemArg): [addr, "template", {params}]

  • addr: Modbus unit address;
  • "template": name of a template in the global modbus settings (keys: serial, baud, poll{regs, irs, coils, dins, delay}, par);
  • {params}: per-parameter objects; a template parameter supports reg/ir/coil/din (address), type, id (suffix code), map, def, prefetch.

Register value types: i16, i32, u16, u32, i8h, i8l, u8h, u8l, x10, 100.

Ctrl: the subitem (template parameter name) takes priority, otherwise the suffix code is matched against the "id" of the template parameters (e.g. S_CMD / S_SET or a custom numeric id).
