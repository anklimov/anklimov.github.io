Detailed Description

Persistent system configuration manager.

Reads and writes the fixed-layout system configuration block (see systemConfigData) stored in flash/EEPROM through a flashStream: MAC address, static network parameters, MQTT/OTA passwords, the remote configuration server URL and assorted control flags. It also keeps track of the ETag of the last downloaded remote config, which is sent back as "If-None-Match" so that the portal server can answer 304 (not modified) and skip the download. The full JSON config load/save/submit workflow (HTTP download from MY_CONFIG_SERVER / CONFIG_SERVER, CRC validation, save to flash) is driven from main.cpp via loadConfigFromHttp(), cmdFunctionSave() and cmdFunctionLoad().
