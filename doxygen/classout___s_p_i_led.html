Detailed Description

Addressable LED strip driver, SPI-like data protocol (CH_SPILED = 11).

Drives a NeoPixel-compatible LED strip (FastLED or Adafruit_NeoPixel backend) from a single data pin.

JSON config (item argument array):

[11, [data_pin, numLeds, ledsType]]

Definition out_spiled.h:58
  • data_pin - the strip data line (default 3);
  • numLeds - number of LEDs on the strip (default 43);
  • ledsType - LED data order / speed (e.g. NeoPixel flags), default BRG 800 kHz.

The channel type is derived from ledsType: RGBW if the strip has a white channel, RGB otherwise. A subItem "from-to" (or a single LED number) limits the command to an LED range, otherwise the whole strip is affected.
