Detailed Description

Relay (ON/OFF output) driver (CH_RELAY = 6 / CH_RELAYX = 16).

Switches a digital output pin. In the simple CH_RELAY form the relay is latched; in the CH_RELAYX form it is a pulse output: after each turn-on the relay stays active for val/255 of the configured period and is switched off by the polling loop.

JSON config (item argument array):

  • CH_RELAY: [6, pin, val, cmd]
  • CH_RELAYX: [16, [pin, period_sec], val, cmd], period in seconds (default 5).

A negative pin number selects an inverted output (active-low).

Commands (/cmd): ON / OFF / TOGGLE / XON / XOFF / HALT / REST, plus a /set percent value which defines the ON duration for CH_RELAYX.
