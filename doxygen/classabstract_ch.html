Detailed Description

Base class of all abstract channels (input and output drivers).

abstractCh defines the lifecycle contract of a driver module: Setup() initializes the hardware and reserves resources, Poll() is called periodically with a cause (POLLING_SLOW/POLLING_FAST/...), Status()/setStatus() track the initialization state (CST_*) and Stop() releases the resources. The class also provides protected publishTopic() helpers that publish a value to a fixed MQTT topic as a retained message.
