Detailed Description

A single LightHub input (digital/analog pin, sensor, encoder, ...).

Input reads one physical input, debounces it, runs the IS_* state machine and executes the actions (commands) configured in the "act" field of the input's JSON object. Supported types are defined by the IN_* flags: buttons, switches, analog inputs, rotary encoders, DHT22/CCS811/HDC1080 sensors, hardware counters and uptime.
