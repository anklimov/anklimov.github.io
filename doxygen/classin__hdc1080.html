Detailed Description

HDC1080 temperature / humidity sensor input (IN_HDC1080 = 6).

Reads the humidity/temperature sensor over I2C at the fixed address 0x40. Polls on the slow polling cycle, resets the I2C bus on a read glitch, publishes the readings on the input "in" section and routes the humidity value to the "hum" key of the input object:

  • /T - temperature (Celsius);
  • /H - relative humidity (percent).

The measured humidity/temperature are also forwarded to the CCS811 sensor (when present) via setEnvironmentalData().
