Detailed Description

Command + value container passed between items, drivers and MQTT.

itemCmd packs a command code (CMD_*), a typed value (ST_* storage) and a topic suffix (S_*) into two 32-bit words (itemCmdStore + itemArgStore). It is the universal currency of the control core: parsed from text or JSON, converted to the channel's storage type, executed by the driver and serialized back to text for status publishing.
