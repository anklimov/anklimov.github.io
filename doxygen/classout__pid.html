Detailed Description

PID controller output driver (CH_PID = 13).

Runs a classic PID loop (PID_v1) and steers an external output item (e.g. a dimmer) with the computed control value.

JSON config (item argument array):

[13,
[kP, kI, kD, dT, alarmTO, alarmVal, outMin, outMax], // PID params, 1..8 elems, or 6 elems
outputExecObj, // command object applied to the controlled output
cascadeExecObj] // optional: object receiving the setpoint (cascade)
  • PID params array, trailing elements are optional: kP, kI, kD, dT (sample time, sec), alarmTO (input-failure timeout, sec, default 600 s), alarmVal (forced output value applied on alarm), outMin, outMax (output limits, default 0..255). A negative kP selects REVERSE direction.
  • The initial setpoint is taken from the item "val" entry (default 20.0).

Control (Ctrl) suffixes:

  • /val - measured input value fed to the controller (also disarms the input-failure alarm);
  • /set - setpoint, additionally forwarded to cascadeExecObj;
  • /cmd - AUTO / HEAT / COOL / ON / OFF / ENABLE / DISABLE / RESET;
  • /ctrl - ENABLE / DISABLE (freeze the control action).

If no /val is received for alarmTO seconds the driver enters the alarm state and forces the output to alarmVal.
